№.03) ：第 3 步：装一个"自动印书机器人"
再点 Add file​ → Create new file，文件名填：
.github/workflows/make-pdf.yml
内容整段照抄（看不懂没关系，这是给机器人看的）：

name: 印成PDF

on: [push]

jobs:
  build:
    runs-on: ubuntu-24.04
    steps:
      - name: 把稿子取过来
        uses: actions/checkout@v5

      - name: 装印书工具和中文书法字体
        run: |
          sudo apt-get update
          sudo apt-get install -y pandoc weasyprint fonts-noto-cjk

      - name: 合成一本 PDF
        run: |
          mkdir -p dist
          printf 'body{font-family:"Noto Sans CJK SC",sans-serif;line-height:1.8}h1{page-break-before:always}\n' > style.css
          pandoc book/*.md -s --toc --pdf-engine=weasyprint --css=style.css -o dist/book.pdf

      - name: 把 PDF 挂出来供下载
        uses: actions/upload-artifact@v5
        with:
          name: book-pdf
          path: dist/book.pdf


Commit changes。
关键：文件名 01-第一章.md、02-第二章.md 前面加数字，机器人就会按 01、02、03 的顺序排版，不会乱。
